# Личные финансы

Один файл `index.html`: откройте его в браузере на телефоне или компьютере. Сервер и установка не нужны.

- Данные хранятся в `localStorage` **только в этом браузере на этом устройстве**.
- Регулярно делайте бэкап: «Данные → Экспорт JSON». Восстановить данные можно через «Импорт JSON».
- При первом запуске загружаются демо-данные. Удалить их можно кнопкой «Очистить и начать с нуля».
