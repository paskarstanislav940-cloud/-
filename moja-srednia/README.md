# Moja średnia

Однофайловый калькулятор успеваемости под польскую школьную систему (оценки 1–6 с `+`/`-`, веса, średnia ważona / arytmetyczna), с импортом копипастом из eduvulcan, симулятором «Что если?» и подсказчиком «сколько нужно до порога».

Откройте `index.html` из этой папки в браузере — сервер не нужен, данные хранятся в localStorage. Бэкап — экспорт/импорт JSON в разделе «Данные».
