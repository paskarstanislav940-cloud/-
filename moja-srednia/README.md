# Moja średnia

Однофайловый сайт для учёбы под польскую школьную систему: оценки 1–6 с `+`/`-` и весами (średnia ważona / arytmetyczna), посещаемость (frekwencja) и расписание. Импорт копипастом из eduvulcan, симулятор «Что если?», подсказчики «сколько нужно до порога» и «сколько уроков посетить до 50%».

Откройте `index.html` из этой папки в браузере — сервер не нужен, данные хранятся в localStorage. Бэкап — экспорт/импорт JSON в разделе «Данные».

Готовые данные для вставки:
- `moje-oceny.txt` — вкладка «Оценки» → Импорт
- `moje-frekwencja.txt` — вкладка «Посещаемость» → Импорт
- `moj-plan-lekcji.txt` — вкладка «Расписание» → Импорт расписания
