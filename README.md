# fioritura

- `index.html` — сайт-портфолио (один файл, EN / RU / UK / PL).
- `lead-parser/` — парсер заказов на сайты и прототипы (Telegram, Reddit, Hacker News). Подробности — `lead-parser/README.md`.

## Windows 11

Дважды щёлкни **`START.bat`** — откроется меню: портфолио, установка и запуск парсера.
Пошаговая инструкция простыми словами — **`README-WINDOWS.txt`**.

| файл | что делает |
|---|---|
| `START.bat` | меню со всеми действиями |
| `setup.bat` | ставит Python (если нужно) и библиотеки парсера |
| `parser.bat` | запускает парсер; при сбое сам перезапускает его |
| `tools/shortcut.ps1` | ярлыки на рабочий стол и автозапуск |
